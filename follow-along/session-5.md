# 5회차: 내 구글 시트와 GAS 웹 앱

- **시작 상태**: 4회차를 끝낸 `C:\ai-class\tumble-dashboard`에서 이어 합니다. 화면이 내 NestJS 서버(`http://127.0.0.1:3000`)의 값으로 "조회 정상"입니다.
- **끝나면 되는 것**: 내 Google 시트의 기록을 읽는 Google Apps Script(GAS) 웹 앱이 생기고, 화면이 그 웹 앱의 값으로 4회차와 같은 배치로 나옵니다. 생산 기록 보기와 출고 기록 보기도 됩니다. 4회차의 내 서버(`backend`)는 켜지 않아도 되고, 화면 코드는 고치지 않습니다.
- **준비물**: 개인 Google 계정으로 로그인한 Chrome, 인터넷, 명령을 칠 PowerShell 창, 화면 서버를 켜 둘 PowerShell 창. 회사·학교 Google 계정은 관리자 정책으로 Apps Script API나 "로그인 없이 누구나" 웹 앱 배포가 막혀 있을 수 있습니다. 막히면 개인 계정으로 처음부터 합니다.

## 시작 전에 (프롬프트 없이 직접 합니다)

1. PowerShell 창(이하 "화면 창")에서 아래를 치고 Chrome에서 `http://127.0.0.1:4173`을 엽니다. 4회차 서버(`backend`)를 켜 둔 창이 있으면 Ctrl+C로 꺼도 됩니다. 이번 회차에는 쓰지 않습니다.

```powershell
cd C:\ai-class\tumble-dashboard
npm.cmd start
```

   서버를 켜 둔 창이 이미 있으면 이 명령을 치지 않고 주소만 엽니다.

2. AI 도구로 `C:\ai-class\tumble-dashboard` 폴더를 열고 새 대화를 시작합니다.
3. Chrome에서 수업에 쓸 개인 Google 계정으로 로그인해 둡니다. 이 회차의 Google 작업은 모두 이 계정 하나로 합니다.

## 진행 방법

- 프롬프트 상자 하나를 통째로 복사해 AI 도구 대화창에 붙여 넣습니다. 앞 번호가 끝난 뒤에 다음 번호를 보냅니다. 새 대화를 열 때마다 5-1의 프롬프트를 먼저 보낸 뒤 하던 번호부터 이어 갑니다.
- AI 도구가 바꾸려는 파일이나 실행할 명령을 물어보면 훑어보고 승인합니다. 도구마다 다를 수 있어서 묻지 않아도 문제가 아닙니다. 단 `icacls`, `Set-ExecutionPolicy`, `npm audit fix`처럼 컴퓨터 설정이나 프로그램을 바꾸는 명령은 승인하지 말고 강사에게 알립니다. 서버를 켜겠다고 하면 거절합니다. 5-1에서 수업 저장소를 받는 `git` 명령도 승인합니다. `npm.cmd run gas:`로 시작하는 명령은 그 번호의 프롬프트에 적힌 명령일 때만 승인합니다. `.clasp.json`, `.env`, `public\config.js`를 열겠다고 하면 승인하지 않습니다. `git commit`을 실행하겠다고 하면 승인하지 말고 "이건 제가 직접 합니다"라고 보냅니다.
- "직접 하기"는 AI 도구에 보내지 않고 내가 합니다. Google 로그인과 권한 승인, 웹 앱 열기는 내가 브라우저에서 합니다. 창을 새로 열었으면 먼저 `cd C:\ai-class\tumble-dashboard`를 칩니다.
- AI 도구가 "이미 되어 있습니다"라고 답하면 그 번호의 "확인"만 해 보고 다음 번호로 넘어갑니다.
- 5-7부터 만드는 `gas` 폴더의 코드는 내 컴퓨터가 아니라 Google에서 실행됩니다. 5-16에서 Google에 올리기 전까지는 파일 안의 글자를 찾는 것까지만 확인합니다. 글자를 찾을 때는 PowerShell 창에서 `notepad gas\Core.gs`처럼 메모장으로 열고 Ctrl+F를 누릅니다. 확인했으면 고치지 말고 닫습니다.
- 이번 회차에는 화면 코드가 바뀌지 않으니 화면 서버는 켜 둔 채 브라우저만 새로고침합니다.
- 꼭 지킬 것: 웹 앱 주소를 아는 사람은 누구나 내 시트의 기록을 읽을 수 있습니다. 배포 주소와 그 주소가 든 `public\config.js`는 다른 사람에게 보내지 않고, 채팅·화면 공유·문서에 옮기지 않습니다. 오류를 AI 도구에 붙여 넣을 때도 `AKfyc`나 `script.google.com`이 든 줄은 빼거나 강사에게 보여 줍니다.

## 5-6. Google 로그인 (직접 하기)

1. PowerShell 창에서 `npm.cmd run gas:login`을 칩니다. 처음에는 clasp를 내려받느라 시간이 조금 걸립니다.
2. 기본 브라우저가 열리면 5-2와 같은 개인 Google 계정을 고르고 허용합니다. "확인하지 않은 앱" 경고가 나오면 clasp가 맞는지 보고 계속 진행합니다. 브라우저가 열리지 않으면 PowerShell 창에 나온 주소를 직접 엽니다.
3. 끝났다는 글이 나온 브라우저 탭은 닫습니다.

- 확인: PowerShell 창에 로그인됐다는 문구가 나오고 명령이 끝납니다. 어느 계정으로 로그인됐는지는 5-17에서 편집기 오른쪽 위로 확인합니다.

```text
자세한 내용은 docs/guide/session-5.md의 "웹 앱 응답과 알림 기록 읽기"와 "기록 탭 읽기"를 참고해 주세요.
```

- 확인: `gas\Code.gs`에 `ContentService`가 있고, "접수한 기록의 수정은 반영하지 않습니다. 새 실습 시트를 만들어 주세요."와 "이 시점의 설정 자료가 없습니다."를 찾으면 보입니다.

## 5-17. 첫 권한 승인과 실습 시트 만들기 (직접 하기)

이 승인을 하기 전에는 웹 앱이 응답하지 않습니다.

1. PowerShell 창에서 `npm.cmd run gas:editor`를 칩니다. 브라우저에 Apps Script 편집기가 열립니다. 열리지 않으면 PowerShell 창에 나온 편집기 주소를 직접 엽니다. 오른쪽 위 계정이 5-2의 개인 계정이 아니면 계정을 바꿉니다.
2. 왼쪽 파일 목록에서 `Setup.gs`를 누르고, 위쪽 함수 선택에 `createTrainingSpreadsheet`가 잡혔는지 봅니다(아니면 직접 고릅니다). "실행"을 누릅니다.
3. "승인 필요" 창에서 "권한 검토"를 누르고 개인 계정을 고릅니다. "Google에서 확인하지 않은 앱" 화면이 나오면 "고급", "텀블공장 개인 백엔드(으)로 이동" 순서로 누릅니다. 내가 올린 코드라서 나오는 화면입니다.
4. 권한 목록의 세 줄("모든 Google Sheets 스프레드시트 확인, 수정, 생성, 삭제", "외부 서비스에 연결", "부재중에 이 애플리케이션을 실행하도록 허용")을 위쪽 "모두 선택"으로 모두 체크합니다. 하나라도 빠지면 6회차 알림이나 트리거에서 권한 오류가 납니다.
5. 아래쪽 "계속"을 누릅니다. 아래로 내리는 화살표에 가려 있으면 그 화살표를 눌러 끝까지 내린 뒤 누릅니다.

- 확인: 아래 실행 로그에 `새 실습 시트: https://docs.google.com/spreadsheets/…` 한 줄이 나오고, 그 주소를 열면 탭 넷(생산 기록, 출고 기록, 설정, 알림 기록)과 `P-seed-0`~`P-seed-4`(수량 20), `S-seed-0`~`S-seed-4`(수량 15)가 처리 상태 "완료"로 보입니다.
- 확인: 시각 칸이 `2026-10-26T01:00:00.000Z` 같은 글자 그대로(왼쪽 정렬) 보입니다. 끝의 `Z`는 세계 표준시라 한국 시각보다 9시간 이르게 적힙니다. 화면에는 한국 시각으로 나옵니다.

## 5-18. 웹 앱 배포와 응답 확인

```text
[5-18] 화면이 부를 웹 앱 주소를 받기 위해, npm 명령 gas:deploy를 한 번만 실행하고 마지막 결과 줄만 알려 주세요.
실패해도 다시 실행하지 말고 그대로 알려 줍니다.
자세한 내용은 docs/guide/session-5.md의 "배포 명령"과 "Google 명령을 실행할 때"를 참고해 주세요.
```

- 확인: AI 답에 "public/config.js에 웹 앱 주소와 timeoutMs 15000을 적었습니다."로 시작하는 줄이 있습니다. "이미 배포 주소가 있습니다. …"가 나오면 이미 배포한 것이니 그대로 다음으로 갑니다.

## 5-19. 화면 확인 (직접 하기)

- 직접 하기: 화면 서버가 켜져 있는지 보고(꺼져 있으면 `npm.cmd start`), http://127.0.0.1:4173 을 열어 새로고침합니다. 4회차 서버는 켜지 않아도 됩니다.
- 확인: "생산 100개 · 목표 120개", "출고 75개 · 목표 100개", 사진 두 장, 시간별 그래프가 나오고, 생산 기록 보기와 출고 기록 보기에 시드 기록이 5행씩 발생 시각 순, 상태 "완료"로 나옵니다. 첫 조회는 5~7초, 그 뒤는 2~3초 걸릴 수 있습니다.
- 알아 두기: 시트를 만든 뒤 30분이 지나면 두 현장이 "새 기록이 늦게 들어오고 있습니다."로 바뀌고 "먼저 확인할 일"에 "텀블공장: 새 기록이 늦게 들어오고 있습니다."가 나옵니다. 마지막 시드 기록이 시트를 만든 시각이라 그렇습니다. "운영 상태"의 알림 전송 카드는 6회차에서 알림을 보내기 전까지 "확인 불가"입니다.

## 5-20. 내 코드 남겨 두기 (직접 하기)

화면 서버를 켜 둔 창이 아닌 PowerShell 창에서 아래를 한 줄씩 칩니다. 둘째 줄은 내 웹 앱 주소가 든 `public\config.js`를 커밋에서 빼는 줄입니다.

```powershell
git add -A
git reset -q public/config.js
git commit -m "5회차 GAS 웹 앱"
```

- 확인: `git status`를 치면 바뀐 파일로 `public/config.js` 하나만 보입니다. `.clasp.json`은 목록에 없습니다.

## 참고

- **Google 쪽 코드를 고친 뒤에는** AI 도구에 아래 상자를 보냅니다. 올리기와 다시 배포를 둘 다 해야 웹 앱이 바뀌고, 주소는 그대로입니다.

```text
고친 Google 쪽 코드를 웹 앱에 반영하기 위해, npm 명령 gas:push와 gas:redeploy를 차례로 한 번씩 실행하고 각 명령의 마지막 결과 줄만 알려 주세요. gas:deploy는 실행하지 마세요.
자세한 내용은 docs/guide/session-5.md의 "Google 명령을 실행할 때"를 참고해 주세요.
```

- **로그인이 만료되면** 명령에서 `invalid_grant`가 나옵니다. PowerShell 창에서 `npm.cmd run gas:login`을 다시 치고, 같은 상자를 다시 보냅니다.
- **강사 API(1단계)나 내 서버(2단계)로 돌아갈 때**는 `API_CONTRACT.md` 9절의 표에 있는 값으로 `public\config.js`의 `apiBaseUrl`과 `timeoutMs`를 바꿉니다.
- **다시 내 GAS 웹 앱(3단계)으로 올 때는 `gas:deploy`를 다시 하지 않습니다.** 주소가 없는 `config.js`에서 `gas:deploy`를 하면 배포가 하나 더 생겨 주소가 바뀝니다. 메모해 둔 `/exec` 주소를 `apiBaseUrl`에 직접 넣고 `timeoutMs`를 `15000`으로 바꿉니다.
- 실습 시트를 새로 만들고 싶으면 편집기에서 `createTrainingSpreadsheet`를 다시 실행합니다. 새 시트가 생기고 웹 앱은 새 시트를 읽습니다. 이전 시트는 그대로 남습니다.

## 5회차 끝 확인

- [ ] `public\config.js`의 `apiBaseUrl`이 `https://script.google.com/macros/s/…/exec`, `timeoutMs`가 `15000`입니다(`notepad public\config.js`로 열어 보고 닫습니다).
- [ ] `npm.cmd run gas:open`으로 열린 브라우저에 `"schemaVersion":1`로 시작하는 JSON이 보이고, 공장 `completed` 100, 창고 75입니다.
- [ ] 4회차 서버를 끈 채로 http://127.0.0.1:4173 에 "생산 100개 · 목표 120개", "출고 75개 · 목표 100개", 사진 두 장, 시간별 그래프가 보입니다.
- [ ] 생산 기록 보기와 출고 기록 보기에 시드 기록이 5행씩, 발생 시각 순, 상태 모두 "완료"로 나옵니다.
- [ ] 기준 시각을 앞 시각으로 고르면 그 시각까지의 기록만 세어 수량이 줄어듭니다.
- [ ] `gas` 폴더에 `appsscript.json`, `Exercises.gs`, `Core.gs`, `Code.gs`, `Setup.gs` 다섯 파일이 있습니다.
- [ ] 5-20에서 내 코드를 커밋했고, `public/config.js`와 `.clasp.json`은 커밋에 들어가지 않았습니다.
