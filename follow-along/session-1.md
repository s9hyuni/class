# 1회차: 화면 틀 만들기

- 시작 상태: 수강생 저장소의 `milestone-0`을 받은 폴더 `C:\ai-class\tumble-dashboard`에서 시작합니다. 강사가 준 파일과 규칙 파일, 1회차 보충 문서가 들어 있고 화면 파일은 아직 없습니다.
- 끝나면 되는 것: `npm.cmd start`로 화면 서버(http://127.0.0.1:4173)가 켜지고, 오늘 운영 화면에 다섯 영역(먼저 확인할 일, 생산·출고 카드, 운영 상태, 기록 처리 상태, 데이터 조회 기록)이 차례로 보입니다. PC에서는 생산·출고 카드가 두 열, 폭 375px에서는 한 열입니다. 숫자는 아직 고정값(생산 100개 · 목표 120개, 출고 75개 · 목표 100개)이고, 버튼과 화면 이동은 2회차부터 붙입니다.
- 준비물: Windows PC, Chrome, Node.js 22 이상, Git for Windows, AI 도구, 수강생 저장소에 초대받은 GitHub 계정.

## 시작 전에 (프롬프트 없이 직접 합니다)

1. 탐색기에서 파일 확장명 표시를 켭니다. Windows 10은 보기 메뉴의 '파일 확장명', Windows 11은 보기 메뉴의 '표시'에서 '파일 확장명'입니다.
2. PowerShell을 열고 `node -v`(`v22.`이나 그보다 큰 번호), `npm.cmd -v`(버전 숫자), `git --version`(버전 숫자)을 차례로 칩니다. "인식되지 않습니다"가 나오면 그 프로그램을 설치하고 PowerShell 창을 닫았다가 다시 엽니다.
3. 아래 명령을 차례로 칩니다. OneDrive가 동기화하는 폴더나 한글이 든 경로는 피합니다. `C:\ai-class` 폴더가 이미 있으면 첫 줄은 건너뜁니다.

```powershell
mkdir C:\ai-class
cd C:\ai-class
git clone -b milestone-0 https://github.com/startup-life/aiops-dashboard-student.git tumble-dashboard
```

4. GitHub 로그인 창이 뜨면 초대받은 계정으로 로그인합니다. 저장소를 찾을 수 없다는 오류가 나오면 초대 수락과 계정을 확인하고 강사에게 알립니다.
5. AI 도구로 `C:\ai-class\tumble-dashboard` 폴더를 엽니다. 파일 탐색기나 AI 도구의 파일 목록에서 `AGENTS.md`, `API_CONTRACT.md`, `README.md`, `docs\guide\session-1.md`, `public\assets\`가 보이면 됩니다.

## 진행 방법

- 이 회차 문서는 GitHub의 수강생 저장소 `main` 화면에서 열어 둡니다. 받은 폴더에는 들어 있지 않습니다.
- 프롬프트 상자 하나를 통째로 복사해 AI 도구 대화창에 붙여 넣습니다. 앞 번호가 끝난 뒤에 다음 번호를 보냅니다.
- AI 도구가 바꾸려는 파일이나 실행할 명령을 물어보면 훑어보고 승인합니다. 도구마다 달라서 묻지 않고 진행해도 문제가 아닙니다. 단 `icacls`, `Set-ExecutionPolicy`, `npm audit fix`처럼 컴퓨터 설정이나 프로그램을 바꾸는 명령은 승인하지 말고 강사에게 알립니다. `.clasp.json`, `.env`를 열겠다고 하거나 `npm.cmd run gas:`, `npm.cmd start`, `git`을 실행하겠다고 하면 승인하지 말고 "이건 제가 직접 합니다"라고 보냅니다.
- "직접 하기"는 AI 도구에 보내지 않고 내가 직접 합니다.
- 프롬프트의 "보충 문서"는 폴더의 `docs\guide\session-1.md`입니다. AI 도구가 읽는 자세한 약속이고, 내가 고치지 않습니다.
- 1-3에서 PowerShell 창을 하나 더 열어 **서버 터미널**로 씁니다. 서버는 이 창에서 켜 두고, 끌 때는 Ctrl+C를 누릅니다. "일괄 작업을 끝내시겠습니까 (Y/N)?"가 나오면 `Y`를 칩니다.
- 1-4부터는 화면 파일만 바꿉니다. 서버는 켜 둔 채로 Chrome에서 새로고침(F5)만 하면 바뀐 내용이 보입니다.
- 화면 색과 간격은 예시와 조금 달라도 됩니다. "확인"에 적힌 글자와 동작이 맞으면 됩니다.
- 더 자세히 시험해 보고 싶으면 보충 문서의 "더 확인해 볼 것"을 봅니다. 하지 않아도 회차를 끝낼 수 있습니다.

## 1-3. 화면 서버 켜기 (직접 하기)

프롬프트는 없습니다.
- 직접 하기: PowerShell 창을 하나 더 엽니다. 이 창이 서버 터미널이고, 수업 내내 켜 둡니다.
- 직접 하기: 서버 터미널에서 아래를 차례로 칩니다.

```powershell
cd C:\ai-class\tumble-dashboard
npm.cmd start
```

- 확인: 서버 터미널의 `> node scripts/serve.mjs` 줄 아래에 `http://127.0.0.1:4173`이 나옵니다.
- 확인: Chrome에서 http://127.0.0.1:4173 을 열면 "오늘 운영" 제목이 보이고, 탭 이름이 "텀블공장 · 오늘 운영"입니다.
- 확인: http://127.0.0.1:4173/abc 를 열면 "요청한 주소의 화면이 없습니다.", "주소가 맞는지 확인해 주세요.", "오늘 운영으로 이동하기"가 보입니다. 링크를 누르면 "오늘 운영"으로 갑니다.
- 확인: http://127.0.0.1:4173/api/v1/snapshot 을 열면 404 화면이 아니라 `{"error":"이 서버는 화면 파일만 보냅니다. …"}` 글자가 보입니다. 자료는 3회차부터 이 화면 서버가 아니라 API 서버에서 받습니다.
- `EADDRINUSE`가 나오면 다른 창에서 서버가 이미 켜져 있는 것입니다. 그 창을 찾아 Ctrl+C로 끕니다.
- (선택) 포트 바꾸기: 서버를 끄고 `$env:PORT=4180; npm.cmd start`로 켜면 `http://127.0.0.1:4180`이 나옵니다. 확인한 뒤 서버를 끄고 `Remove-Item Env:PORT`를 친 다음 `npm.cmd start`로 다시 켭니다.
